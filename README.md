Faculty Availability Management System

A Flask-based web application designed to help students quickly check faculty availability within the university campus. The system allows faculty members to update their presence status manually while displaying real-time availability, cabin details, and last seen information on a centralized dashboard.

The project includes:

Faculty registration and management
Real-time status updates
Search and department-based filtering
Responsive and user-friendly interface
SQLite database integration
Flask backend with dynamic routing
Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Flask (Python)
Database: SQLite

Future Enhancements
Authentication system for secure access
Automated presence detection using IoT
Cloud deployment and scalable architecture
Mobile-friendly optimization
